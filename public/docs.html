cara pakai api

aktivasi premium alight motion via http request · buat bot & otomasi

intinya gini

API ini ngaktifin premium Alight Motion lewat email. Kamu kirim alamat email → kami kirim link verifikasi ke email itu → user salin link-nya dan kirim balik ke kamu → kamu tukar link itu → akun langsung premium.

Cuma 2 panggilan API. Sisanya user yang buka email.

sebelum mulai: api key

Kalau aktivasi lewat web ini langsung, gak perlu api key. Api key cuma perlu kalau kamu manggil dari luar · bot, script, aplikasi sendiri.

Caranya: kirim lewat header x-api-key di setiap request. Jangan taruh di URL — kredensial di URL bisa kecatat di log server, riwayat browser, dan Referer.

x-api-key: APIKEYLU

Belum punya key atau key kedaluwarsa? Hubungi admin.

langkah 1

kirim link ke email user

Panggil dari bot / script kamu. Ganti email & api key-nya:

curl -X POST https://v.axjet.xyz/api/send-link \ -H "x-api-key: APIKEYLU" \ -H "content-type: application/json" \ -d '{"email":"emailuser@gmail.com"}'
contoh balasan sukses
{ "success": true, "email": "emailuser@gmail.com", "message": "link dikirim ke emailuser@gmail.com. cek inbox / spam." }
contoh balasan gagal
{ "success": false, "message": "email gak valid." }

Kalau success: true, email user langsung dapet link verifikasi dari Alight Motion.

langkah 2

tukar link → premium aktif

1
User buka email, salin link panjang dari Alight Motion, kirim ke bot kamu.
2
Kamu buka URL ini · ganti email & masukin link yang barusan disalin (jangan ada spasi):
curl -X POST https://v.axjet.xyz/api/verify-link \ -H "x-api-key: APIKEYLU" \ -H "content-type: application/json" \ -d '{"email":"emailuser@gmail.com","magicLink":"LINK_DARI_EMAIL"}'
contoh balasan sukses (dipotong)
{ "success": true, "message": "verifikasi berhasil, premium aktif.", "data": { "status": "ACTIVE", "membershipStatus": "PREMIUM_ACTIVE", "planName": "Alight Motion Pro / Member", "validUntil": "1 September 2027", "expiryTimeMillis": 1819796995395, "engine": "standard", "email": "emailuser@gmail.com", "uid": "GSyZUOi...", "idToken": "eyJhbGci...", "refreshToken": "AM3-vEv..." } }
contoh balasan gagal (link kedaluwarsa)
{ "success": false, "message": "magic link kedaluwarsa / sudah dipakai. kirim ulang (langkah 1)." }

Selesai! Akun user langsung premium. Kamu tinggal baca validUntil buat kasih tahu user masa aktifnya.

isi balasan langkah 2 · apa artinya

fieldartinya
statusACTIVE = premium nyala
validUntiltanggal terakhir premium aktif, contoh “1 September 2027”
expiryTimeMillistanggal yang sama, format angka (gampang buat dihitung program)
idTokentoken akun · simpan kalau mau panggil endpoint lain
refreshTokentoken panjang · buat perpanjang tanpa verifikasi ulang
enginejalur server yang kepakai (internal, cuekin aja)

bonus: perpanjang tanpa verifikasi ulang

Punya refreshToken dari langkah 2? Bisa perpanjang premium langsung tanpa minta link email lagi:

curl -X POST https://v.axjet.xyz/api/reactivate \ -H "x-api-key: APIKEYLU" \ -H "content-type: application/json" \ -d '{"refreshToken":"TOKENLU"}'
contoh balasan sukses
{ "success": true, "message": "Token berhasil di-refresh dan premium diperpanjang.", "data": { "status": "ACTIVE", "idToken": "eyJhbGci...", "refreshToken": "AM3-vEv..." } }

info publik (tanpa api key)

Cek server hidup atau tidak:

https://v.axjet.xyz/api/status
contoh balasan
{ "status": "online" }

Cek statistik aktivasi:

https://v.axjet.xyz/api/stats
contoh balasan
{ "success": true, "total": 296, "today": 2 }

masalah umum

Link dari email gak jalan?

Link cuma hidup ± 5 menit dan cuma bisa dipakai sekali. Ulangi langkah 1 buat kirim link baru.

Dapet “unauthorized”?

Api key salah / kosong / kedaluwarsa. Cek lagi header x-api-key sudah terpasang benar.

Email gak dapet link?

Suruh user cek folder spam / junk. Kalau tetep kosong, tunggu 1–2 menit lalu ulangi langkah 1.

Premium gak nempel di akun?

Pastikan user nggak buka link dari email · link harus masih segel pas disalin ke kamu. Link yang udah dibuka gak bisa ditukar.

jangan share api key ke orang lain. Satu key = tanggung jawab kamu.
